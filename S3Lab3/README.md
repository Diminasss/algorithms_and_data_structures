# Лабораторная работа №3. Дерево поиска и максимальная куча

Задания 3 и 11 варианта 10. В работе реализованы двоичное дерево поиска и максимальная двоичная куча. В качестве данных используется модель студента, а ключом служит средний балл.

## Реализовано

### `BinarySearchTree`

- добавление записи с проверкой уникальности ключа;
- поиск и проверка наличия по среднему баллу;
- удаление листа, узла с одним потомком и узла с двумя потомками;
- текстовое представление дерева;
- сохранение в `Tree.txt` и восстановление из файла.

### `MaxHeap`

- построение кучи из двусвязного списка;
- вставка с восстановлением свойства кучи;
- получение максимального элемента;
- поиск, подсчёт и удаление записей по ключу;
- сохранение в `Heap.txt` и восстановление из файла.

`main.py` демонстрирует все операции и выполняет замеры добавления и удаления 1000 элементов.

## Файлы

| Файл | Назначение |
|---|---|
| `Student.py` | модель студента; поле `key` содержит средний балл |
| `BinarySearchTree.py` | двоичное дерево поиска |
| `MaxHeap.py` | максимальная двоичная куча |
| `DubblyLinkedList.py` | хранилище элементов кучи |
| `Tree.txt` | пример сохранённого дерева |
| `Heap.txt` | пример сохранённой кучи |
| `main.py` | демонстрационный сценарий и замеры времени |

## Запуск

Дополнительные зависимости не требуются.

```powershell
cd S3Lab3
python main.py
```

Во время запуска файлы `Tree.txt` и `Heap.txt` перезаписываются демонстрационными данными.

## Основные оценки сложности

| Операция | Средняя | Худшая |
|---|---:|---:|
| поиск, вставка и удаление в дереве | `O(log n)` | `O(n)` |
| вставка в кучу | `O(log n)` | `O(log n)` |
| получение максимума | `O(1)` | `O(1)` |
| поиск элемента в куче | `O(n)` | `O(n)` |

Оценки для кучи приведены для её классического представления в массиве. В этой работе куча хранится в двусвязном списке, поэтому индексный доступ требует дополнительного прохода и увеличивает фактическое время операций.
