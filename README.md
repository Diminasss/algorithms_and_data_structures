# Алгоритмы и структуры данных

Учебный репозиторий с лабораторными работами по алгоритмам и структурам данных на Python. В работах структуры реализованы вручную: от двусвязного списка и стека до дерева поиска, кучи и взвешенного графа.

## Лабораторные работы

| Работа | Тема | Основные алгоритмы и структуры |
|---|---|---|
| [Лабораторная №2](S3Lab2/README.md) | Линейные структуры | двусвязный список, стек, проверка скобочной последовательности |
| [Лабораторная №3](S3Lab3/README.md) | Деревья и кучи | двоичное дерево поиска, максимальная куча, сохранение в файл |
| [Лабораторная №4](S3Lab4/README.md) | Сортировки | гномья сортировка, сортировка вставками, подсчётом и слиянием |
| [Лабораторная №5](S3Lab5/README.md) | Поиск | поиск Фибоначчи и интерполяционный поиск |
| [Лабораторная №6](S3Lab6/README.md) | Графы | список смежности, обход в ширину, алгоритм Дейкстры |

## Требования

- Python 3.10 или новее;
- пакет [`Faker`](https://pypi.org/project/Faker/) для генерации тестовых данных в лабораторных №4 и №5.

Создание виртуального окружения и установка зависимости:

```bash
python -m venv .venv
```

Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
python -m pip install Faker
```

Linux и macOS:

```bash
source .venv/bin/activate
python -m pip install Faker
```

## Запуск

Каждую работу следует запускать из её каталога: так локальные импорты и пути к файлам будут разрешены корректно.

```powershell
cd S3Lab2
python main.py
```

Для другой лабораторной замените `S3Lab2` на нужный каталог. Скрипты выводят демонстрацию операций и результаты простых замеров времени в консоль.

## Структура репозитория

```text
.
├── S3Lab2/    # двусвязный список и стек
├── S3Lab3/    # двоичное дерево поиска и максимальная куча
├── S3Lab4/    # алгоритмы сортировки
├── S3Lab5/    # алгоритмы поиска
├── S3Lab6/    # графы, BFS и алгоритм Дейкстры
└── COPYRIGHT
```

Лабораторная №3 перезаписывает `Tree.txt` и `Heap.txt`, а лабораторная №6 — `vertex.txt`. Эти файлы используются для демонстрации сериализации и последующего чтения структур.
