# Лабораторная работа №5. Алгоритмы поиска

Вариант 7. Работа демонстрирует поиск книги по количеству страниц в двух самописных структурах данных.

## Реализовано

- поиск Фибоначчи в двусвязном списке;
- интерполяционный поиск в динамическом массиве;
- сортировка списка подсчётом перед поиском;
- гномья сортировка массива перед поиском;
- проверка, что коллекция отсортирована по возрастанию;
- обработка отсутствующего значения и выхода за диапазон ключей.

Оба метода возвращают индекс найденной книги. Перед поиском коллекция должна быть отсортирована по полю `pages` по возрастанию, иначе создаётся исключение `NotSortedException`.

## Файлы

| Файл | Назначение |
|---|---|
| `book.py` | модель книги |
| `DubblyLinkedList.py` | двусвязный список, сортировка подсчётом и поиск Фибоначчи |
| `Massive.py` | динамический массив, гномья сортировка и интерполяционный поиск |
| `main.py` | позитивные и негативные сценарии, а также замеры времени |

## Зависимости и запуск

Для генерации набора из 10 000 книг используется пакет `Faker`.

```powershell
python -m pip install Faker
cd S3Lab5
python main.py
```

Сценарий сначала проверяет поиск на небольших наборах данных, затем измеряет заполнение, сортировку и поиск для списка и массива.

## Сложность поиска

| Алгоритм | Типичная оценка | Худший случай |
|---|---:|---:|
| поиск Фибоначчи | `O(log n)` сравнений | `O(log n)` сравнений |
| интерполяционный поиск | `O(log log n)` при равномерном распределении | `O(n)` |

В этой реализации поиск Фибоначчи обращается к элементам двусвязного списка по индексу. Такое обращение само требует линейного прохода, поэтому фактическое время отличается от оценки числа сравнений классического алгоритма.
