# Лабораторная работа №4. Алгоритмы сортировки

Вариант 7. Работа сравнивает четыре алгоритма сортировки на самописных динамическом массиве и двусвязном списке. Элементами коллекций служат книги с автором, издательством, количеством страниц, ценой и ISBN.

## Реализовано

| Структура | Алгоритм | Поле сортировки | Направление |
|---|---|---|---|
| динамический массив | гномья сортировка | автор | по возрастанию |
| динамический массив | сортировка вставками | цена | по убыванию в текущей реализации |
| двусвязный список | сортировка подсчётом | количество страниц | по убыванию |
| двусвязный список | сортировка слиянием | автор | по убыванию |

Методы возвращают новую отсортированную коллекцию, поэтому исходный массив или список можно вывести после операции и убедиться, что он не изменился.

## Файлы

| Файл | Назначение |
|---|---|
| `book.py` | модель книги |
| `Massive.py` | динамический массив, гномья сортировка и сортировка вставками |
| `DubblyLinkedList.py` | двусвязный список, сортировка подсчётом и слиянием |
| `main.py` | примеры сортировок и замеры на сгенерированных данных |

## Зависимости и запуск

Для генерации авторов и ISBN используется пакет `Faker`.

```powershell
python -m pip install Faker
cd S3Lab4
python main.py
```

Демонстрационный сценарий сортирует небольшой набор книг, затем запускает каждый алгоритм на 247 случайно сгенерированных записях и выводит время выполнения.

## Теоретическая сложность

| Алгоритм | Время | Дополнительная память |
|---|---:|---:|
| гномья сортировка | `O(n²)` | `O(1)` без учёта копии результата |
| сортировка вставками | `O(n²)` | `O(1)` без учёта копии результата |
| сортировка подсчётом | `O(n + k)` | `O(n + k)` |
| сортировка слиянием | `O(n log n)` | `O(n)` |

Здесь `k` — диапазон значений количества страниц.
