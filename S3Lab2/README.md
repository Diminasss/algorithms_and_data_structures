# Лабораторная работа №2. Двусвязный список и стек

Вариант 7. Работа посвящена ручной реализации двух линейных структур данных и их базовых операций.

## Реализовано

### Двусвязный список `DubblyLinkedList`

- добавление элемента в начало и конец;
- вставка и удаление по индексу;
- доступ по индексу с выбором ближайшего конца списка;
- проверка наличия элемента;
- разворот списка;
- получение длины и проверка на пустоту.

### Стек `Stek`

- добавление элемента `push`;
- извлечение верхнего элемента `pop`;
- просмотр верхнего элемента `get_data`;
- получение количества элементов.

Функция `stek_test` в `main.py` использует стек для проверки правильности последовательности круглых, квадратных и фигурных скобок.

## Файлы

| Файл | Назначение |
|---|---|
| `DubblyLinkedList.py` | узел и реализация двусвязного списка |
| `Stek.py` | узел, стек и исключение пустого стека |
| `main.py` | демонстрация операций, проверка скобок и небольшой замер времени |

## Запуск

Дополнительные зависимости не требуются.

```powershell
cd S3Lab2
python main.py
```

Скрипт последовательно проверяет добавление, индексирование, поиск, вставку, удаление и разворот списка, после чего демонстрирует операции со стеком.

## Основные оценки сложности

| Операция | Сложность |
|---|---|
| добавление в начало или конец списка | `O(1)` |
| доступ, вставка или удаление по индексу | `O(n)` |
| поиск элемента в списке | `O(n)` |
| `push`, `pop`, просмотр вершины стека | `O(1)` |
| проверка скобочной последовательности | `O(n)` |
