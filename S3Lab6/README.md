# Лабораторная работа №6. Графы

Вариант 12. Работа посвящена взвешенному графу, обходу в ширину и поиску кратчайшего пути. Демонстрационный граф описывает расстояния между городами Сибири.

## Реализовано

- обобщённый ориентированный или неориентированный граф на списках смежности;
- добавление вершин и взвешенных рёбер;
- перечисление вершин, рёбер и смежных рёбер;
- сохранение графа в текстовый файл и чтение из него;
- обход в ширину (`bsf` в исходном коде);
- алгоритм Дейкстры на базе приоритетной кучи;
- вспомогательные структуры: очередь, множество и двоичная куча.

`main.py` строит неориентированный граф из пяти городов, сохраняет его в `vertex.txt`, загружает копию, находит кратчайший маршрут из Новосибирска в Новокузнецк и выполняет обход в ширину.

## Файлы

| Файл | Назначение |
|---|---|
| `graph.py` | граф, вершины и рёбра, файловый ввод-вывод |
| `dxtra.py` | алгоритм Дейкстры |
| `Shirina.py` | обход графа в ширину |
| `heap.py` | двоичная куча с изменяемым приоритетом |
| `queue.py` | очередь на односвязных узлах |
| `set.py` | множество поверх словаря |
| `vertex.txt` | сохранённый пример графа |
| `main.py` | демонстрационный сценарий |

## Формат файла графа

Каждая строка содержит начальную вершину, конечную вершину и целочисленный вес ребра:

```text
Новокузнецк Томск 425
Томск Новосибирск 266
```

Для неориентированного графа в файл записывается одна строка на пару связанных вершин.

## Запуск

Дополнительные зависимости не требуются.

```powershell
cd S3Lab6
python main.py
```

Во время запуска `vertex.txt` перезаписывается текущим демонстрационным графом.

## Сложность

При использовании списка смежности обход в ширину работает за `O(V + E)`. Алгоритм Дейкстры с двоичной кучей имеет оценку `O((V + E) log V)`, где `V` — количество вершин, а `E` — количество рёбер.
